51 · Glossary

Glossary

File
Physical bytes in a workspace.
Logical File
Identity tracked by FileId across renames/moves.
FileId
Authoritative identity of a logical file (UUID).
Revision
One immutable state of one logical file.
RevisionId
Stable identifier of a Revision.
RevisionSet
Logical transaction grouping revisions for review/acceptance.
RevisionSetId
Stable identifier of a RevisionSet.
FileHead
Pointer to currently accepted revision.
ContentRef
Stable reference to content bytes by hash/size (sha256:<64 hex>).
ObjectRef
Reference to stored content object.
DiffArtifact
Derived comparison between revisions.
ApplyTransaction
Physical projection and recovery transaction.
Logical Commit
Acceptance of reviewed RevisionSet.
Workspace Projection
Materialized files from accepted state.
.vsn
Self-contained file-local companion sidecar for revision data.
VSN-1
Self-contained container format for BRP revision data.
RCMP-1
Canonical binary encoding for BRP.
MembersDigest
SHA-256 of canonically encoded RevisionSet members.
Generation
Monotonic counter for atomic container writes.
CommitMarker
Record indicating accepted state boundary.
